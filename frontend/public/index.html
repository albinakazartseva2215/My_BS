Тон — черновой тестовый фронтенд

Простой интерфейс поверх готового API сервиса записи (server/). Без дизайна — задача только проверить, что API работает: обычные формы, списки и кнопки. Ошибки API показываются текстом прямо на странице.

Как пользоваться

  1. Зарегистрируйтесь или войдите (регистрация / вход).
  2. Посмотрите услуги и мастеров, выберите услуги и мастера.
  3. Посмотрите свободное время выбранного мастера на дату.
  4. Создайте запись на выбранный слот.
  5. В личном кабинете — список своих записей, перенос, отмена.
  6. Админ-панель — все записи, управление услугами/мастерами (нужна роль admin).
